# فريق إدارة تيتانيوم

نظام داخلي لمتابعة المشاريع والمهام والمسؤولين والموافقات، وواجهته الرئيسية سكرتير ذكي على واتساب.

## المكونات
- `app/` لوحة Next.js (شاشة متابعة، ويمكن جعلها للعرض فقط عبر `DASHBOARD_READONLY=1`).
- `lib/` المنطق: الصلاحيات (`management-actions.ts`)، السكرتير (`secretary-*.ts`)، الموافقات (`approvals.ts`)، القواعد (`rules.ts`)، قاعدة المعرفة (`knowledge.ts`)، تسجيل الدخول برمز واتساب (`whatsapp-login-*.ts`).
- `services/whatsapp-bridge/` خدمة خاصة تربط رقم واتساب بالنظام (نص، صوت، استطلاعات، تسليم دائم).
- `tests/` اختبارات `node --test`.

## التشغيل المحلي
```
npm install
cp .env.example .env.local   # ثم عبّئ القيم
npm run dev
```

## الإنتاج
```
npm run build
npm start
```
يتطلب Node.js 22. تُحفظ البيانات والملفات المرفوعة داخل `TITANIUM_DATA_DIR` (افتراضيًا `data/`) وهو مستثنى من Git.

## الدخول
- الدخول برمز مؤقت يُرسل إلى رقم واتساب المسجّل للموظف عند `WHATSAPP_LOGIN_ENABLED=1`.
- بدون تفعيل واتساب يعمل الدخول بالكود الرقمي؛ باسم يحدد كود المدير عند التشغيل الأول ثم أكواد الفريق.

## الأمان
- لا تُرفع ملفات `.env` أو قاعدة البيانات أو مفاتيح Groq إلى المستودع.
- الصلاحيات تُفرض في الخادم دائمًا؛ نموذج اللغة يقترح فقط ولا ينفذ.
- كل إجراء يُسجَّل في `audit_logs`.
